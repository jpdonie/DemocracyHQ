# Map label glyphs

`Noto Sans Medium/*.pbf` are signed-distance-field glyph ranges used by MapLibre GL JS to draw map labels without
calling any third-party tile or font service. They were copied unmodified from
https://github.com/protomaps/basemaps-assets (fonts/Noto Sans Medium), which builds them from Google's Noto Sans.

Noto Sans is licensed under the SIL Open Font License 1.1 (see `OFL.txt`).

# Text fonts

The site's text fonts, Archivo and Newsreader, are bundled from the Fontsource packages
`@fontsource-variable/archivo` and `@fontsource-variable/newsreader` into the build's `assets/` folder. Both are
licensed under the SIL Open Font License 1.1; their copyright notices and licence texts are in
`LICENSE-Archivo.txt` and `LICENSE-Newsreader.txt`.
